# 文法道场

在具体场景中练习日语自动词与他动词、に／で／へ等助词关系。独立网站，复用活用道场的存储保护、有效计时、日语字体和注音对齐。

自动词与他动词课程按25种词形对应模式排列；7组参考资料未收录的高频词对也归入相同模式，并标记为「补充例词」。每种模式内结合 JPDBv2㋕ 与 Jiten Global 的词形、读音排名，由常见到较少见排列。25种模式是达标目标，172组词对是轮换例词池：每种模式只抽取最多3组代表词对，不要求逐组完成。题卡显示当前词形模式，实际判断仍以句中角色和语境为准。

在线使用：[https://l-m-sherlock.github.io/bunpo-dojo/](https://l-m-sherlock.github.io/bunpo-dojo/)

## 本地开发

需要Node.js 22.13或以上版本。

```sh
npm ci
npm run dev
```

开发地址为终端显示的 `/bunpo-dojo/` 路径。构建和预览：

```sh
npm run build
npm run preview
```

## 验证

```sh
npm run validate
```

验证包括逐题内容与审核哈希审计、行为测试、全对和首错后全对模拟、类型检查、Lint及生产构建。当前完整冻结范围为172组自他词对、10项助词用法、858个场景；实际达标目标为25类自他词规律与10项助词用法，共35项。草稿与正式在用题目分开，只有当前哈希匹配独立批准报告的卡片才可接入。

计划见 [实施计划](docs/implementation-plan.md)，题库范围见 [scope](content/scope.json)，词频来源与合并方式见 [词对排序说明](content/references/PAIR_FREQUENCY_NOTICE.md)，复用边界见 [复用记录](docs/reuse.md)，语言制作要求见 [内容规则](docs/content-authoring.md)。

## 学习记录

默认本地保存，无账号和后端。提示、揭晓及过早复测单独记录；自由挑战与常规复测分队列。普通学习轮最多12题，没有新的可推进场景时提前结束；最近场景和词条跨轮保存用于避重。题前说明当前属于复测、间隔、补齐达标还是巩固，课程页列出类别尚缺的作答、场景、代表词对及自他方向覆盖。具体词对答错后仍按同一词对换场景复测；未抽到的词对不阻止课程完成。旧版逐词对进度会自动合并到对应类别。备份导入先验证并确认覆盖，不累计重复成绩，也不接受活用道场的备份。多标签页冲突会停止写入，存储不可用时可导出当前内存进度。

当前实现采用静态Vite构建，可部署在支持子路径的静态站点。工作基路径为 `/bunpo-dojo/`，部署前应按实际仓库或域名调整并核对字体资源。
