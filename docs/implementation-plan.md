# 文法道场实施计划

2026年10月13日。开发一个独立的日语用法辨析网站，复用活用道场的基础功能。工作目录为 `bunpo-dojo`，工作名称为「文法道场」；域名和远端仓库可在发布时确定。实施范围包含代码、内容审核、本地运行和验收。

## 后续范围变更

用户后续要求移除“存在与活动地点”的「へ」干扰项，并为「に／で」各增加10个场景；随后要求覆盖哈呀文章中的全部自他词例，并把自他词练习放到学习路线最后。当前总量为858：地点40题、移动40题、关系40题、综合30题、自他词708题，共182个学习目标。原250题计划和270题地点扩充保留为历史快照；当前变更见[文章词对覆盖](article-pairs-expansion.md)。

## 产品范围

首版固定为25组高频自他动词、10项助词用法及250个独立场景。具体词对、用义、题目ID和分工冻结在 `content/scope.json` 与 `content/requirements.json`。250个场景包含自他动词120题、助词100题、综合辨析30题；选择和输入是同一道题的两种呈现方式，不重复计算场景数量。

自他动词覆盖开关、变化、物品操作和活动开始结束。每个词对至少两个自动词场景、两个他动词场景。采用明确词义与具体对象，不把自动词一律解释为无意志动作，不把他动词等同人为故意。

助词覆盖存在地点、活动地点、移动目的地、乘坐对象、离开位置、经过路径、接受者、具体时点、工具或交通方式、移动目的。按关系区分知识点，不将所有「に」合并为一个成绩。综合题在同句中给出其他关系，只挖一个目标空，每题只独立评估一个目标；题干已经提供的规则不加分。

## 页面和练习

首页兼作练习入口，展示推荐进度、课程选择及继续按钮。练习正面优先显示短中文场景和日语挖空句；解释、完整译文、正确读音和答案在答后显示。所有日语使用自托管日语字体，汉字有可切换注音。

课程分为地点辨析、自他动词、移动与路径、其他助词关系、综合辨析。推荐顺序按前四组建立基础后进入综合；用户可以随时选课，避免把已有学习者当作新手强制锁课。

自适应每轮最多12题；同轮优先使用尚未出现且能推进达标的场景，候选耗尽时提前结算，不用已达标题补满。跨轮保存最近36个场景与词条作为软避重依据，复测和学习推进优先级高于避重。课程切换和未作答结束不计错。自由挑战支持多选课程、立即挑战综合、持续出题直到主动结束。挑战单栏作答并正确突出顶部菜单。练习和统计导航保留当前输入、提示和反馈；统计页不响应答题快捷键。

题目支持选择和短输入，可随时切换；提示后即标为辅助条件，刷新无法清除帮助状态。输入期间忽略IME的Enter；第一次有效提交计一题，快速重复点击和快捷键不得重复记录。答后展示完整句、译文、选项解释与对照，按钮和反馈在1366×768及手机宽度下可见，必要时滚动反馈到视口。

## 判题和学习证据

每题显式保存所有正确选项。目的地的「に／へ」同时成立时两者都接受，输入假名读音或标准汉字词形同样接受。判题只做NFKC与空白规范化，不以近似字符串推测认知错误，不允许任意替换词或助词。输入模式下，只有自他词共同词根中的一处替换、遗漏、插入或相邻颠倒，且其余完整词形唯一对应正确选项时，才提示笔误并允许无计分重输；助词、自他类别、词尾差异和有竞争解释的输入不适用。

错误选项逐项标明「句法不合适」或「表达另一件事」。后一种反馈说明选项可表达的事实以及与场景的区别；不能把日语成立的句子称为不存在的语法。未知输入只提示当前题范围和已审核答案，不编造自动诊断。

成绩以词对和助词用法为单位，独立无提示作答积累成绩；答后重做、提示和巩固只记辅助。识别与输入分别记录，首版达标主要依据独立正确表现及不同场景覆盖，不用综合题为已经给出的基础规则加分。

失败、提示和揭晓产生待复测。复测保持相同辨析目标，并至少间隔两道其他目标整题；自他动词换场景，助词优先换词条与场景。题型换成输入不会创造新的目标或额外复测。题库不足时明确安排间隔或巩固，不能默默清除任务。挑战复测与常规复测分队列，同一目标不重复产生义务，允许用户显式移动队列。

选题优先合格复测、待复测间隔题、当前未达标目标及已学巩固；题前明确说明本题属于哪一种安排。小题池放开最早排除项；无限挑战意味着可以持续出题，不代表题目永不重复。结算展示下一轮实际焦点。课程页同时展示达标尚缺的独立作答次数、正确率、场景数及自他方向覆盖。

## 复用边界

来源固定为活用道场提交 `67459b9b500ad660f0225f55d736789616f91025`。新网站独立安装、运行、构建和存储，不运行时引用相邻目录。

## 数据和审核

题目对象包含ID、课程、主知识点、辨析家族、词条键、中文场景、前后句段、候选词形与读音、正确答案集合、逐选项解释、完整译文、提示与来源。只使用一处完整目标空。参考资料支持规则；原创句明确为原创，不能冒称教材原句。

制作流程沿用仓库用法卡skill的逐句自然度与注音要求，适配新题目schema。先做六组各3题试稿，独立审核通过后分包扩写，每份审核包最多16题。作者使用 `gpt-6-luna max`，独立审核使用 `gpt-6-sol medium`。冻结作者文件，逐卡报告保存当前对象SHA-256、实际完整句、正确集合、选项语义、译文、注音、状态和具体理由。审核者不能审自己的稿，主代理负责结构、哈希和接入，不能替代语言批准。

原稿及返修稿保留。未决不算通过，改稿须重新审核；不存在可信候选时记录实际尝试，按skill的有效失败规则处理。首版每个目标有审核合格场景，不通过的精确场景可以重写，但不能靠删掉目标缩小本次范围。最终250题全部有有效当前哈希批准，草稿不打包进网站。

## 实施步骤和验收门禁

1. 冻结范围、创建独立工程、保存复用来源与计划；250个要求无重复或漏项。
2. 完成试稿schema与审核流水线，审核反馈用于修正规则后扩写；所有多答案与不同义选项均逐句审。
3. 实现判题、独立计分、复测和选题；验证未知输入、合理替代、提示、重复提交、间隔、小题池和队列隔离。
4. 实现练习、挑战、统计、注音和备份；使用统一状态写入保障答案、统计和日志一起保存。存储失败保留内存备份，冲突时阻止覆盖并提示重新加载。
5. 接入250题并审计每个冻结目标的集合覆盖、独立场景数、来源及当前哈希；更换内容时暂存无法复测的历史任务，不伪造正确证据。
6. 全对与混合模拟必须完成全部目标并解除常规复测；记录题数、重复场景和最长同目标连续题，避免用总题数掩盖循环。
7. 完成全量测试、类型检查、Lint、构建；浏览器验证桌面、短屏及手机、正反面注音、两个模式导航和备份回读。

本地验收完成后提供运行地址、源码、审核进度和实际结果。远端仓库创建、推送与公开发布按用户后续要求进行。
