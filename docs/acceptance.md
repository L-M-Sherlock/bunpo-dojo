# 文法道场首版验收

2026年10月13日。首版已完成本地实现与生产构建验证，工作名称为「文法道场」。源码和内容位于独立仓库 `bunpo-dojo`；尚未创建远端仓库、提交或公开部署。

后续地点课程扩充见[地点更新记录](location-expansion.md)，完整文章词对覆盖见[当前更新记录](article-pairs-expansion.md)；以下250题及33项测试为首版验收快照。

## 范围与内容

25组自他动词、10项助词用法、250个独立场景均已接入。对应35个学习目标与5门课程。

|课程|场景数|
|---|---:|
|存在与活动地点|20|
|自动词与他动词|120|
|移动与路径|40|
|时间与其他关系|40|
|综合用法辨析|30|
|合计|250|

每张卡都有匹配当前内容哈希的独立 `gpt-6-sol medium` 批准报告，待处理范围为零。作者使用 `gpt-6-luna max`。原稿、返修稿及独立报告保留在 `content/deliveries` 和 `content/reviews`；当前有效批准由 `content/approved-index.json` 绑定。结构检查、注音锚点检查和语言审核分别记录，未将结构通过代替自然度批准。

完整审计结果见 [content-audit.json](content-audit.json)，冻结原始要求与基线校验和分别位于 `content/requirements.json` 和 `content/baseline.json`。运行时集合与要求完全相等，无重复ID、遗漏或过期批准。每组词对基础题至少覆盖两个自动词场景、两个他动词场景；每个目标至少有三个独立场景。

## 功能与行为验证

33项测试通过，覆盖全部在用题目的答案集合与干扰项类别，并验证真实React页面的作答、重复提交、IME输入、刷新保留提示、统计导航保留输入、无限挑战第26题、常规与挑战队列隔离、备份回读及损坏数据恢复。实际浏览器生成的JSON下载也已用本站导入器校验通过。

另外验证了多标签写入冲突、存储失败保留内存快照、暂停与恢复已退出题池的复测任务、同字不同读音的重输保护，以及助词发音「え／お」不能替代实际书写「へ／を」。只评估当前题实际要求的目标，不为题干提供的其他语法规则加分。

`npm run validate` 的内容审计、全量测试、模拟、类型检查、Lint和构建全部通过。构建的主JavaScript约615KB，gzip约144KB；Vite保留大于500KB的提示，字体另按Unicode分片加载。

## 学习路线模拟

|模拟|整题数|完成目标|常规待复测|最长同目标连续题数|重复场景数|
|---|---:|---:|---:|---:|---:|
|全对|175|35 / 35|0|2|5|
|每个目标首次答错，之后全对|350|35 / 35|0|2|132|

结果见 [simulation-results.json](simulation-results.json)。重复场景表示有限题库中的重练：有些词对仅有4个基础场景，而达标需要至少5次独立证据；首错后的模拟还需要恢复近期正确表现。场景重复不被伪装为新的内容。此为规则可完成性验证，不是学习效果实验。

## 浏览器和显示

实际浏览器检查了1366×768桌面与390×844手机视口，两者未出现横向溢出。答后解析与下一题按钮均可滚动到视口内；手机挑战隐藏常规课程侧栏。多选挑战的开始按钮在短屏保持可见，菜单状态与当前模式一致。还用合成备份展示了整个题库中最长的24字注音句段，确认手机宽度下能够换行；没有使用个人学习备份。

Chrome实际字形检查确认正文与注音使用自托管Noto Sans JP，返回 `isCustomFont: true`。所有字体CSS及248个WOFF2分片存在，OFL许可随资源保存。短输入、词对标题和其他日语标签均有日语语言标记。
