# 日语注音对齐

题卡保存完整书面读音，但页面只在能确定词界时自动拆分 ruby。重复假名可能产生多种字符串切法，例如「母は来週」的读音以连续三个「は」开头；这类内容不能靠最短或最长匹配猜测。

`src/data/ruby-overrides.json` 保存显示层的词级分段，不修改题卡对象，因此不会使内容审核哈希失效。它由当前题库和 UniDic 候选生成，生成后仍需查看实际分段：

```sh
uv run --no-project --with 'fugashi[unidic-lite]' \
  python scripts/generate-ruby-overrides.py
npm run audit:ruby
```

`audit:ruby` 验证每条映射能分别重组正文和读音，并扫描全部在用题目。出现新的歧义句段而没有明确映射时，审计失败；运行时会暂时隐藏该整段注音，不会把一串假名错误地平均铺在整句上。

新增或修改题卡后应运行该审计。映射是排版元数据，不能用来更改词义、日语正文或作者填写的完整读音。
